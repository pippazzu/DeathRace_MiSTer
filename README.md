# Death Race / Destruction Derby

MiSTer FPGA core for Exidy's Death Race (1976) and Destruction Derby (1975), rebuilt from the complete TTL schematics and various recordings of original boards.

Analog steering and acceleration (with compatible MiSTer mains, four steps including 0) are supported, separate MRAs for 15khz interlaced video output are included for consumer CRT users.

## Options

**Tone:** Original boards included a knob to regulate the soundboard's tone. Default is the one closest to most recordings.

**Speaker:** The original cabinet had two speakers, one for each player. Default options mixes the two into one dual mono output.

**Shifter:** Default option is separate Drive and Reverse buttons, as on the original cabinet, which has a lever with two switches. The alternative is a Drive/Reverse toggle on the Drive button.
